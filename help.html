PhyBLE 使用說明

ESP32 接上感測器，透過藍牙把資料送到 iPad 的 phyphox。老師課前用燒錄站準備板子；學生照接線引導接線，在 phyphox 量測、換感測器、匯出資料。

老師・課前一次燒錄板子並設定組別

  1. 用電腦版 Chrome 或 Edge 打開燒錄站

    iPad、手機、Safari、Firefox 都不支援 USB 燒錄。

  2. USB 線接上 ESP32

    要用能傳資料的線，有些便宜的線只能充電。

  3. 選組別

    點數字格或用 − / ＋。藍牙名稱會是 PHY-G01、PHY-G02…

  4. 選起始感測器

    選這堂課要用的感測器，下面會出現接線表。之後學生也能在 iPad 上換。

  5. 按 燒錄韌體＋設定組別

    跳出視窗時選 USB 序列埠（通常叫 CH340 或 CP210x），約 40 秒完成。

  6. 看到「完成！藍牙名稱 PHY-G01」就拔下來

    網頁會自動跳到下一組，插上下一塊板子繼續燒。建議在板子上貼標籤寫 G01、G02。

一直停在「連線中」：按住板子上的 BOOT 鍵再按燒錄，開始寫入後放開。

只想換組別或感測器、不用重燒：選好後按 只改組別／感測器。

開機燈號（板子上的藍燈）

先閃組別
長閃 = 十位、短閃 = 個位
第 12 組 = 長 1 下、短 2 下
快速連閃 10 下

藍牙等待連線

老師・隨時檢查板子裡是什麼程式

  1. 插上 USB，按 查看板子資訊

    板子會重開一次，約 2 秒後顯示藍牙名稱、組別、目前感測器、韌體版本。

  2. 看下面的提示

    綠色「已是最新版」就不用動；橘色「建議更新」時，按「用這塊板子的組別與感測器重燒」，再按燒錄。

  3. 讀不到任何資訊

    板子裡是別的程式或還沒燒過，直接按燒錄即可。

提示意思
已是最新版和燒錄站上的版本相同
較早的多感測器版沒有版本號，建議更新
第一版只有超音波，沒有感測器模式，建議更新

學生照接線引導接線

  1. 打開接線引導，選這堂課的感測器

    平板、電腦都能開。上方選單選感測器。

  2. 選板子種類

    數板子單邊有幾支腳：15 支選「30 腳」，19 支選「38 腳」。

  3. 按「下一步」一步一步接

    圖上發光的那條線就是這一步要接的；右邊會寫線的顏色和兩端位置。

  4. 看懂孔位

    字母在前、數字在後：g15 是 g 列第 15 排。同一直排的 a–e 相通、f–j 相通；下方 + / − 兩條長軌整排相通。

  5. 接完核對整張圖

    按「顯示完整接線」。立體圖可以拖曳旋轉、滾輪縮放；「俯視」最好對照孔位。

所有感測器的 VCC 接 3.3V，不要接 5V / VIN；所有 GND 要接在一起。

模組腳位順序以板子上的絲印為準；和圖上不同時，照「功能名稱」接（VCC 接 + 軌、GND 接 − 軌、訊號接指定的 GPIO）。

學生・iPad用 phyphox 連上自己組的板子

  1. 板子插電，等藍燈每秒閃一下

    表示已經在等 iPad 連線。

  2. 打開 phyphox，按右下角橘色 ＋

    選「從藍牙裝置新增實驗」（英文介面：Add experiment from Bluetooth device）。

  3. 在清單中點自己組的 PHY-Gxx

    看清楚組別再點。一塊板子同時只能連一台 iPad。

  4. 出現實驗畫面後按上方 ▶ 開始

    藍燈變成恆亮。標題會寫目前的感測器，例如「溫度 PHY-G03」。

phyphox 會把實驗留在首頁清單。下次可以直接點開，但換過感測器後要重新加入，見下一節。

學生・iPad換成這堂課的感測器

  1. 滑到最後一頁「換感測器」

    實驗上方的分頁列最右邊。

  2. 在「感測器」選單選這堂課的感測器

    例如「2 光閘計時 (XD-51)」。

  3. 按上方 ▶

    板子收到後會儲存設定並自動重開（約 3 秒），phyphox 會顯示連線中斷，這是正常的。

  4. 回到 phyphox 首頁，用 ＋ 重新加入同一個 PHY-Gxx

    新的實驗標題會是新的感測器，例如「光閘計時 PHY-G03」。

選好的感測器會記在板子裡，拔電後也不會消失；下次上課同一個實驗直接用就好。

學生・iPad匯出實驗資料

  1. 量完先按 ⏸ 暫停

    資料會保留在畫面上。

  2. 按右上角 ⋮，選「匯出資料」

    英文介面：Export Data。

  3. 選格式

    Excel（.xlsx）最方便做圖表；CSV 可以給任何試算表或 Python 使用。

  4. 存到檔案或分享

    可存到 iPad「檔案」、AirDrop 給老師，或上傳到雲端硬碟、Google Classroom。

欄位名稱已設定好，例如「t (s)」「T1 (°C)」「遮光時間 (s)」。重新量測前可以從 ⋮ 選「清除資料」。

以上 iPad 畫面為示意圖，實際文字與位置依 phyphox 版本與語言設定略有不同。

參考各感測器重點

感測器接到 ESP32phyphox 會顯示注意
1 溫度 DS18B20DQ → GPIO4溫度對時間，可接兩支探頭裸探頭要加 4.7 kΩ 電阻（模組板已內建）
2 光閘 XD-51DO → GPIO27遮光時間、間隔、次數開機時槽內不要有東西；速度 = 擋片寬 ÷ 遮光時間
3 轉速 霍爾DO → GPIO26轉速 rpm、週期轉盤貼磁鐵，用滑桿設定磁鐵數；開機時磁鐵不要停在感測器前
4 電壓電流 INA219SDA → 21、SCL → 22電壓、電流、功率、V-I 圖待測電路負極要和 ESP32 GND 接在一起；上限 26V、3.2A
5 馬達 L9110SA-IA → 25、A-IB → 33滑桿調輸出 −100～100%，轉速、電壓、電流馬達用電池盒供電，不能用 ESP32 的 3.3V；要共地

疑難排解常見問題

狀況怎麼辦
iPad 找不到 PHY-Gxx確認藍燈每秒在閃；別台 iPad 是否已連著這塊板子（一次只能連一台）；iPad 藍牙有沒有開、有沒有允許 phyphox 使用藍牙。
圖表沒有資料有沒有按 ▶；標題是不是這堂課的感測器；接線照引導、VCC 接 3.3V、GND 有共地。
藍燈快速連閃 10 下板子還沒設定組別，請老師用燒錄站設定。
換感測器後畫面沒變要回 phyphox 首頁用 ＋ 重新加入；舊的實驗畫面不會自動更新。
溫度顯示不出來DS18B20 黃線接 GPIO4，裸探頭一定要有 4.7 kΩ 電阻。
光閘 / 霍爾一直沒反應或亂跳開機時槽內有東西或磁鐵停在感測器前：清空後按板子 EN 鍵重開。
燒錄站打不開序列埠關掉 Arduino IDE 序列埠監控和其他燒錄分頁，USB 拔掉再插回。
