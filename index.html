PhyBLE 燒錄站

ESP32 多感測器 → iPad phyphox。選組別與起始感測器、插上 USB、按一下：韌體、組別、感測器一起寫入。藍牙名稱 PHY-G01、PHY-G02…；學生之後也能在 phyphox 的「換感測器」分頁自己切換。

這塊 ESP32 的藍牙名稱將會是
PHY-G01
組別 1 ~ 99
接線引導（給學生）→麵包板步驟圖，立體可旋轉，選感測器看接法 使用說明（含 phyphox 操作）→

韌體

起始感測器

無線更新用 Wi-Fi　未設定

燒錄或「只改組別／感測器」時會一起寫進板子。只支援 2.4 GHz、輸入密碼就能連的 Wi-Fi；學校網路若要網頁登入或帳號驗證，請用手機熱點。設定好後，學生在 phyphox「換感測器」選「↻ 無線更新韌體」，或按住板子 BOOT 鍵 5 秒（藍燈快閃）再放開，板子就會自己上網更新。

準備就緒。插上 ESP32，選好韌體與組別後按「燒錄」。

序列埠監看與紀錄 

      

        
        
        
      

    

  






  

    
1　接線
照上方接線表。感測器 VCC 一律接 3.3V，GND 共地；每種感測器腳位固定，互不衝突。

    
2　燒錄
用 Chrome 或 Edge 開本頁，按燒錄後選擇 USB 序列埠（CP210x / CH340）。連不上時按住板子的 BOOT 鍵再試。

    
3　看燈號
板載藍燈（GPIO2）開機先閃組別：長閃 = 十位、短閃 = 個位（第 12 組 = 長 1 短 2），未設定則快閃。之後每秒短亮 = 等待連線，恆亮 = phyphox 已連上。

    
4　iPad phyphox
phyphox → ＋ → 新增藍牙實驗 → 選 PHY-Gxx → ▶ 開始。要換感測器：到最後一頁「換感測器」選好並按 ▶，板子重開後重新加入。資料用右上選單「匯出」。
